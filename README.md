# Copperfind

Personal Home Depot penny-list app. Open it on your phone and use **Add to Home Screen**.

`data/penny-list.json` is refreshed daily from public shopper reports. Penny prices are store-specific and never guaranteed. Not affiliated with The Home Depot.

Store locations: © OpenStreetMap contributors, available under the Open Database License (openstreetmap.org/copyright). ZIP code centers: U.S. Census Bureau 2024 ZCTA Gazetteer (public domain).
